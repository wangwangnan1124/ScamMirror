# Changelog

All notable changes to ScamMirror are documented here.

## [0.1.0] - 2026-07-26

### Added

- Browser-local, explainable analysis of suspicious Chinese messages
- Four synthetic demo scenarios
- Three-level risk output with grounded evidence excerpts
- Stop-action checklist and independent verification steps
- Privacy-preserving family help message
- Responsive and keyboard-accessible interface
- Synthetic evaluation dataset and automated baseline report
- Product requirements, architecture, evaluation, privacy, security, and contribution documentation
- Automated lint, build, rendering, rule, and evaluation checks

### Safety boundaries

- No model API or API key required
- No message persistence
- No automatic URL or QR-code opening
- No “certainly safe” output
- Synthetic evaluation results are not presented as real-world accuracy
